# Coreboot Software & Hardware Feature Catalog — ASRock H61M-S1 PLUS (`v26.11.2`)

Comprehensive catalog of Coreboot + EDK2 `UefiPayloadPkg` software and hardware features applicable to the **ASRock H61M-S1 PLUS** (`H61M-VS4 G/A 1.00`, LGA1155, Intel H61 `8086:1c5c`, Nuvoton `NCT6776F/D`, 8 MiB `W25Q64` SPI flash).

**Status Legend**:
- **Enabled & Verified**: Compiled, flashed internally (`--ifd -i bios`), and observed working on physical hardware.
- **Enabled (Built-In / Partial Test)**: Compiled and initialized; specific edge hardware (e.g., `VGA1`, `1600 MT/s` DIMMs, `2x8` bifurcation riser) not yet attached.
- **Available / Optional**: Supported by upstream Coreboot `df45ea2c49b4` / EDK2 `f248a68be339` and board silicon, ready to toggle via Kconfig/devicetree/ifdtool.
- **Not Supported / Hardware-Limited**: Blocked by H61 silicon fuses or missing physical board traces/chips.

## 1. Boot Payloads & Chainloading

With the upgrade from a 4 MiB SPI part (`W25Q32`) to an **8 MiB `W25Q64`** (`0x680000` = `6.5 MiB` `COREBOOT` CBFS, `~4.5 MiB` currently empty), multiple payloads and standalone utilities fit comfortably in flash alongside EDK2.

|---|---|---|---|---|---|---|

## Quick-Pick Feature Recipes

1. **Unattended Headless Homelab / Compute Node** *(Closest to Current Live Config)*
   - Start from `configs/h61m-s1-plus-8mb.defconfig` (COM1 `115200` only, LPT1 disabled, `Above-4G` enabled for `Tesla P4` / GPUs, `VT-x`/`VT-d` enabled, `SmartFan IV` + `9` runtime CFR options).
   - Set via OS CLI:
     ```bash
     sudo h61-coreboot-config set power_on_after_fail on
     sudo h61-coreboot-config set fb_debug_pause 0s
     sudo h61-coreboot-config set fan_profile performance
     sudo h61-coreboot-config wol on
     ```
2. **Bloat-Free Privacy Build (Soft-Disabled Intel ME)**
   - Assemble full 8 MiB ROM with `--me-cleaner` (`me_cleaner.py -S`) using `outputs/h61m-s1-plus-coreboot-8mb-full-mecleaned.rom` and flash once with an external SPI programmer on socketed `U3`.
3. **High-Security Verified Workstation**
   - Add `LPC TPM 1.2/2.0` hardware module on `LPC/TPM1`, enable `CONFIG_TPM2=y` + `CONFIG_VBOOT=y` (`RW A/B` fits in `8 MiB`), set `CONFIG_BOOTMEDIA_SMM_BWP=y`, and enable EDK2 Secure Boot with custom enrolled keys.
4. **Dual-Boot Diagnostic Swiss-Army-Knife Flash**
   - Keep EDK2 as primary payload and enable `CONFIG_SEABIOS_SECONDARY_PAYLOAD=y`, `CONFIG_COREINFO_SECONDARY_PAYLOAD=y`, and `CONFIG_MEMTEST86PLUS_SECONDARY_PAYLOAD=y` inside the `~4.5 MiB` free CBFS space.
