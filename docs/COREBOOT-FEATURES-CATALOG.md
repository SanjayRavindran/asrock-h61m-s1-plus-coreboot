Comprehensive catalog of Coreboot + EDK2 `UefiPayloadPkg` software and hardware features applicable to the **ASRock H61M-S1 PLUS** (`H61M-VS4 G/A 1.00`, LGA1155, Intel H61 `8086:1c5c`, Nuvoton `NCT6776F/D`, **4 MiB `W25Q32`** & **8 MiB `W25Q64`** SPI flash).

> [!TIP]
> **Status Legend & Runtime Configuration**:
> - **Enabled & Verified**: Compiled, flashed, and observed working on physical hardware (`v26.11.4`).
> - **Enabled (Built-In / Partial Test)**: Compiled and initialized; specific edge hardware (e.g., `VGA1`, `1600 MT/s` DIMMs, discrete LPC TPM module, `2x8` bifurcation riser) not yet attached.
> - **Available / Optional**: Supported by upstream Coreboot `df45ea2c49b4` / EDK2 `f248a68be339` and board silicon, ready to toggle via Kconfig/devicetree/ifdtool.
> - **Not Supported / Hardware-Limited**: Blocked by H61 silicon fuses or missing physical board traces/chips.
> - Use [`scripts/h61_coreboot_config.py`](../scripts/h61_coreboot_config.py) (`sudo h61-coreboot-config`) to configure all **10 runtime CFR BIOS options** directly from Linux.

## 1. Boot Payloads & Chainloading

With the upgrade from a 4 MiB SPI part (`W25Q32`) to an **8 MiB `W25Q64`** (`0x680000` = `6.5 MiB` `COREBOOT` CBFS, `~4.41 MB` currently empty), multiple payloads and standalone utilities fit comfortably in flash alongside EDK2.

| **Delete-Key Dedicated USB Boot Menu** | EDK2 `BootManagerMenuApp` + `PlatformBootManagerLib` + `TerminalConIn.c` | `patches/0002-edk2-delete-key-usb-boot-menu.patch` (`USB_ONLY` LoadOptions, `SCAN_DELETE` hotkey, `TerminalTypePcAnsi` VT220 `\x1b[3~`) | **Enabled & Verified** | Tapping **`Delete`** always opens **`Select USB Boot Device:`** even for **1** (`USB Device` live-verified with Ubuntu Server USB!) or **>1** USB bootable disks (or safe `"No bootable USB devices found."` popup + `R` rescan + `ESC` cancel); works on PS/2, USB HID, & serial | Creates hidden `Boot0001* USB Boot Menu` (`LOAD_OPTION_CATEGORY_APP`, `USB_ONLY`) | Built into all `v26.11.4` ROMs (`Del` at `5s` boot prompt) |

| **`nvramcui` / `tint` Secondary Payloads** | Config / Fun | `CONFIG_NVRAMCUI_SECONDARY_PAYLOAD=y` / `CONFIG_TINT_SECONDARY_PAYLOAD=y` | Available | Legacy CMOS NVRAM editor (`nvramcui`) for non-UEFI payloads, or Tetris in flash (`tint`) | `H61M-S1 PLUS` uses UEFI `SMMSTORE` CFR rather than CMOS option table for board settings | Select under `Secondary Payloads` |
